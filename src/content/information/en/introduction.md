# About Me

I am a developer focused on the balance between technology, systems, and aesthetics.

I work in web and systems engineering, while continuously exploring AI-related fields including AI agents, machine learning, deep learning, and computer vision. Rather than individual model capabilities, I care more about how intelligent systems are designed, orchestrated, and constrained to run stably in real-world scenarios.

To me, technology is both an engineering challenge and a form of expression—
code structure, model boundaries, and interface whitespace all shape the user experience.
