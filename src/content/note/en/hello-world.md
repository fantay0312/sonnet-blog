## Introduction

Welcome to Zen Blog! This is a blog system that combines the best features of two excellent Astro themes.

## Features

### Eastern Aesthetics

- Calligraphy font decorations
- Zen-inspired color scheme
- Clean and elegant design

### Modern Features

- Bilingual support (Chinese/English)
- Light/Dark mode toggle
- Pagefind full-text search
- RSS subscription
- GitHub contributions heatmap
- Skills showcase

## Content Categories

- **Home (序章)** - Prologue content on homepage
- **Notes (文记)** - In-depth articles and technical notes
- **Jottings (随笔)** - Random thoughts and daily records
- **About (絮述)** - About page

## Getting Started

1. Edit `site.config.ts` to configure site info
2. Add content in `src/content/` directory
3. Run `pnpm dev` to preview
4. Run `pnpm build` to build
